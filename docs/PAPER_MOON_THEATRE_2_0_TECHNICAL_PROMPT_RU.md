# Paper Moon Theatre 2.0: технический промт

Ты senior React Native / Expo / Reanimated engineer и motion designer. Доработай
только стартовую сцену LOUSA Moon, не меняя Firebase, маршрутизацию, хранение
сессии, API и текущую форму входа.

## Цель

Собрать взрослую, премиальную и спокойную Paper Moon Theatre 2.0 для женского
wellness-приложения. Это не мультфильм и не детская подвеска. Пользователь
должен видеть цельную сцену: облачная завеса открывается, луна поднимается по
тонкой нити, появляется бренд, затем в центральную область входит настоящий
экран входа или регистрации.

## Обязательная режиссура

1. Первый кадр: тёплый фон, плотная завеса бумажных облаков из трёх планов.
   Луна находится ниже центра и соединена с верхним краем короткой нитью.
2. С 120 мс луна плавно уходит вверх. Нить должна укорачиваться вместе с ней;
   нельзя двигать луну отдельно от нити.
3. Облака расходятся влево и вправо разными скоростями: дальние остаются
   краями кадра, передние уходят дальше. Центральный слой растворяется вверх.
4. В открывшемся центре кратко появляется `LOUSA` / `MOON`, тонкая линия и
   подпись `Твоя забота, в своём ритме`.
5. Бренд исчезает до появления реального UI. Настоящий экран авторизации
   поднимается в центральную область; не рисовать фальшивую форму поверх него.
6. Вся normal-анимация длится 3.3-3.7 секунды. Reduced Motion показывает
   неподвижную красивую сцену и мягко открывает UI без пространственных
   перемещений.

## Визуальные правила

- Палитра: ivory, cream, light beige, dusty rose, muted plum.
- Луна без лиц, звёзд, внутренних персонажей, глянца, 3D-пластика и текста.
- Облака на трёх планах, с достаточной плотностью в начале и чистым центром в
  финале. Нижняя треть не должна выглядеть пустой.
- Использовать реальный загруженный брендовый шрифт, а не системный serif, если
  он уже доступен в приложении.
- Не использовать градиентные пятна, резкие пружины, бесконечное движение,
  анимацию layout-свойств или декоративный шум.

## Инженерные ограничения

- Только `transform` и `opacity` через Reanimated для движущихся слоёв.
- До скрытия native splash обязательно дождаться layout и декодирования всех
  PNG. При любой ошибке ассета обязателен спокойный fallback и watchdog.
- Не добавлять 4096px PNG в runtime. Для старта применять раздельные PNG/WebP
  1024-1536px или меньше, заранее preload через `expo-asset`.
- Сохранить `auth-paper-thread`, `getThreadHeightForMoonOffset`, таймауты
  native splash, fallback и тесты контракта старта.
- Не менять package name, подпись APK, backend URL, Firebase-конфигурацию,
  Google OAuth и данные пользователя.

## Проверка перед выдачей APK

1. Запустить unit-тесты Paper Moon и TypeScript typecheck.
2. Собрать `:app:assembleQa` с API backend.
3. Проверить APK через `unzip -t`.
4. При доступном Android по Wi-Fi ADB: установить APK, сделать cold start,
   снять кадры на 0.4 с, 1.6 с, 2.4 с и убедиться, что нет белого/чёрного
   экрана, облака раскрываются, нить прикреплена к луне и UI появляется.
